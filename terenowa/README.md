# Beboki — Gra Terenowa v1

Mobilna gra terenowa Katowic: GPS → punkt → fragment historii → zagadka → odblokowana scena → trop → NFC/AR → XP.

## Cel v1
- mapa z punktami gry
- geofencing: quest aktywuje się po wejściu w promień punktu
- zagadki i odpowiedzi
- odblokowywanie scen/filmów
- zapis postępu lokalnie
- przygotowanie pod AR i NFC

## Ważne
Współrzędne w `locations.json` są demonstracyjne i przed użyciem terenowym muszą zostać zweryfikowane na miejscu. Nie publikujemy fikcyjnych punktów jako istniejących instalacji.

## Inspiracje technologiczne
Projekt można później połączyć z GPS + WebXR/Three.js. Istniejące open-source projekty pokazują, że GPS-anchored AR i location-based scavenger hunts można realizować w przeglądarce.
